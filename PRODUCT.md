# Product Document

## 📌 What we built
An AI-powered Expense Tracker that helps users manage expenses, set budgets, and get AI-based financial suggestions.

## 🎯 Target Users
- Students
- Working professionals
- Anyone managing personal finances

## ❗ Problem
Manual expense tracking is inefficient and lacks insights.

## 💡 Solution
- Add and track expenses
- Set monthly budget
- Visual dashboard with charts
- AI assistant for financial advice

## ⚖️ Tradeoffs
- Focused on core features instead of advanced analytics
- Basic AI integration for simplicity

## 📦 Scope
- User authentication
- Expense management
- Budget tracking
- AI assistant
